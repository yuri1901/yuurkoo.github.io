# Вулиці Львова — Express, EJS та NeDB

Вебзастосунок читає наявні файлові колекції з `../lab-nedb/` і не копіює базу даних.

## Запуск

```bash
npm install
npm start
```

Відкрийте у браузері:

- [http://127.0.0.1:3000/streets](http://127.0.0.1:3000/streets) — усі вулиці;
- [http://127.0.0.1:3000/houses](http://127.0.0.1:3000/houses) — усі будинки;
- `/houses?streetId=...` — фільтрація будинків за ідентифікатором вулиці.

Сторінки генеруються шаблонізатором EJS, а дані надходять із `streets.db` та `houses.db` у папці `lab-nedb/`.
